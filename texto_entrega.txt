Introducción
La gestión de tareas es una actividad cotidiana tanto en el ámbito académico como en el profesional, ya que permite organizar actividades, establecer prioridades y asegurar el cumplimiento de objetivos dentro de tiempos determinados. En contextos universitarios, esta práctica es especialmente importante porque facilita la planificación de actividades, la revisión de entregas, la organización del estudio y la administración del tiempo. Sin embargo, cuando estas tareas se gestionan de manera manual o dispersa, es común que se presenten problemas como la pérdida de información, la falta de seguimiento y la dificultad para priorizar actividades importantes.

Con el avance de la tecnología, las aplicaciones web han tomado un papel fundamental en la optimización de este tipo de procesos. Las plataformas digitales permiten registrar, consultar, actualizar y eliminar información de forma rápida y segura, además de ofrecer interfaces accesibles para distintos tipos de usuarios. En este sentido, el desarrollo de una aplicación web para la gestión de tareas no solo responde a una necesidad funcional, sino también a la necesidad de aplicar principios de ingeniería de software que favorecen la calidad, el mantenimiento y la escalabilidad del sistema.

Por esta razón, este proyecto se enfocó en la creación de una aplicación web para la gestión de tareas utilizando arquitectura hexagonal, buenas prácticas de programación y principios SOLID. La solución se diseñó con una separación clara entre la lógica de negocio, la capa de infraestructura y la interfaz del usuario, con el fin de generar un sistema ordenado, extensible y fácil de mantener. De esta forma, se buscó demostrar cómo una aplicación puede resolverse de manera estructurada, aplicando patrones apropiados para un desarrollo profesional y académico.

Además, la implementación contempla tanto la parte del backend como la del frontend, permitiendo una experiencia completa para el usuario final. La combinación de estas dos capas genera una solución funcional, moderna y coherente con los estándares actuales de desarrollo web. El proyecto no solo responde a una necesidad práctica, sino que también evidencia el dominio de conceptos fundamentales de diseño de software, refactorización y organización del código.

Objetivos
- Diseñar e implementar una aplicación web moderna para la gestión de tareas.
- Aplicar la arquitectura hexagonal para separar la lógica de negocio de la infraestructura técnica.
- Utilizar buenas prácticas de código limpio y refactorización.
- Implementar un sistema con frontend y backend bien definidos.
- Garantizar la organización y disponibilidad de los datos mediante persistencia en base de datos.
- Validar la funcionalidad mediante pruebas del sistema.
- Subir el proyecto a GitHub como evidencia del trabajo realizado.

Desarrollo
La aplicación se desarrolló con una estructura modular y organizada en capas. En primer lugar, se definió la capa de dominio, donde se establecieron las entidades y los contratos del repositorio. Esta capa representa la lógica central del sistema y está enfocada en el problema a resolver, sin depender directamente de detalles tecnológicos como la base de datos o la interfaz web.

Posteriormente, se implementó la capa de aplicación, en la cual se manejaron los casos de uso principales del sistema. Estas operaciones permiten crear tareas, listarlas, modificar su estado de completitud y eliminarlas según sea necesario. Este enfoque garantiza que la lógica de negocio permanezca independiente de la forma en que se reciben las solicitudes o de cómo se almacenan los datos.

La infraestructura se desarrolló con Flask para la API del backend y SQLite para la persistencia. La comunicación entre frontend y backend se realizó a través de endpoints HTTP, lo que favorece la interoperabilidad y simplifica futuras extensiones del sistema. El frontend se implementó con React, proporcionando una interfaz moderna y funcional para la interacción del usuario.

Además, se aplicaron principios SOLID y buenas prácticas de refactorización, como la separación de responsabilidades, la encapsulación de reglas de negocio y la inversión de dependencias. Esto redujo el acoplamiento entre componentes y favoreció la reutilización y el mantenimiento del código. Asimismo, se realizaron pruebas automatizadas para verificar el comportamiento esperado de las operaciones del sistema.

Conclusión
El proyecto cumple con los objetivos planteados al desarrollar una aplicación web funcional para la gestión de tareas, utilizando una arquitectura bien organizada y principios de ingeniería de software modernos. La aplicación demuestra la capacidad de separar la lógica del negocio de la infraestructura técnica, logrando un sistema más claro, escalable y fácil de mantener.

La integración de Flask y React permitió construir una solución completa, con interfaz de usuario amigable y acceso a datos confiable. Además, la implementación de buenas prácticas de desarrollo, junto con la validación mediante pruebas, refleja un nivel adecuado de calidad académica y técnica. El proyecto quedó finalizado y publicado en GitHub como evidencia del trabajo realizado.
